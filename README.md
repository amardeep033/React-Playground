# React Playground

Collection of small React practice projects, each focused on a specific pattern or feature set.

## Projects

### ANIME(setup_routing_list_card_nav)

Anime and book-themed practice app built around routing, list rendering, reusable cards, and navigation UI.

### CART(reducer)

Shopping cart practice app centered on reducer-based state management, modal flows, and shared cart context.

### LIB(search_filter_pagination)

Library-style app for practicing search, filtering, and pagination on a list of items.

### TODO(form_auth_modal_localstorage)

Todo and user-management practice app covering forms, auth flow, modal interactions, and local storage.

## Getting Started

Each project is an independent Create React App setup.

```bash
cd "ANIME(setup_routing_list_card_nav)"
npm install
npm start
```

Repeat the same pattern for the other project folders.

## Common Scripts

From inside any project folder:

- `npm start` runs the development server.
- `npm test` runs tests in watch mode.
- `npm run build` creates a production build.

## Structure

- Root folder: workspace-level documentation and Git settings.
- Project folders: isolated React apps.
- Nested `src` folders: feature code and shared components for each app.
- Nested `public` folders: static HTML and manifest assets.
