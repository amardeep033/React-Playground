# CART App

React reducer practice project focused on cart state, item lists, and modal-driven cart interactions.

## Run

```bash
npm install
npm start
```

## Structure

- `public/`: static HTML shell.
- `src/cart/`: cart modal UI.
- `src/extra/`: header and icon components.
- `src/meals/`: meal listing and item presentation.
- `src/shared/`: shared card component and cart context.
